## DEFINITION OF PROMPT TYPES

Naïve Prompt
A naïve prompt is a short, general, and unstructured instruction that provides limited information to the AI.
Example:
Write a story about a student.

Basic Prompt
A basic prompt provides detailed instructions about the task, context, audience, format, and expected result.
Example:
Write a 300-word motivational story about a college student who faces academic difficulties but successfully achieves a goal. Include a clear beginning, problem, solution, and conclusion.

## DETAILED ANALYSIS

The comparison showed that prompt structure has a significant effect on the generated output.

Naïve prompts can be useful for general exploration, but they often leave important requirements unspecified. As a result, ChatGPT has to make assumptions about what the user wants.

Basic prompts reduce this ambiguity by providing clear instructions. They help ChatGPT understand the task, target audience, desired format, level of detail, and expected outcome.

Therefore, basic prompting generally produces responses that are more relevant, organized, and practical.

## LIMITATIONS OF NAÏVE PROMPTING
Naïve prompting has several limitations:

1.Responses may be too general.
2.Important details may be missing.
3.Output format may not match expectations.
4.Technical answers may require clarification.
5.Responses may lack sufficient depth.
6.Users may need multiple follow-up prompts.
7.The AI may make assumptions about the user's requirements.

## BEST USE CASES FOR NAÏVE PROMPTS

Naïve prompts are useful when the user wants an open-ended response.
They can be used for:

1.Brainstorming

## BEST PRACTICES FOR PROMPTING CHATGPT

<img width="686" height="386" alt="image" src="https://github.com/user-attachments/assets/32d288d5-b1fd-4f8a-b4f4-0f2a70c34692" />

1. Be Specific
Clearly state what the AI should do.

2. Provide Context
Give the necessary background information.

3. Mention the Audience
Specify whether the response is for students, beginners, or professionals.

4. Define the Format
Mention whether you need a table, paragraph, list, code, or report.

5. Add Constraints
Specify word count, number of points, duration, or other requirements.

6. Provide Examples
Examples can help communicate the expected result.

7. Use Clear Language
Avoid unnecessary or confusing instructions.

8. Verify the Response
Important factual and technical information should be checked before use.

## SUMMARY OF FINDINGS

The experiment compared Naïve Prompting and Basic Prompting across 18 different scenarios.

The major findings were:

Naïve prompts generated general responses.
Basic prompts produced more focused responses.
Basic prompts were more effective for technical tasks.
Structured prompts improved planning tasks.
Providing context improved relevance.
Specifying the output format improved organization.
Naïve prompting remained useful for brainstorming and open-ended creativity.

Overall, Basic Prompting provided greater control over the generated response and generally produced more useful outputs.

## CONCLUSION

The experiment successfully compared Naïve Prompting and Basic Prompting using ChatGPT across different test scenarios.

The results showed that a simple prompt can generate a reasonable response, but it may not fully satisfy a specific requirement. A basic prompt provides additional context, instructions, constraints, and expected output, allowing ChatGPT to produce a more relevant and structured response.

Therefore, effective prompt engineering is an important skill when working with Generative AI. Users can improve AI-generated results by clearly explaining their requirements and specifying the desired output.
